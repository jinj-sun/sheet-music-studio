## 仍有的产品边界

- 显式连梁时值、中途 divisions/属性变化、复杂装饰信息删除等暂使用 XML 编辑；不强行重排导入乐谱。
- score-timewise 目前只保留与编辑源 XML，不提供图形编辑或 MIDI。
- 反复/跳转、倚音、踏板、装饰/奏法、八度线、微分音等演奏解释不完整，界面逐项告知，需明确接受近似试听/MIDI；XML/MXL 仍保留原记号。
- MIDI 最多 15 个独立通道，节拍量化到 9600 PPQ，不是乐谱的可逆存储格式。
- OMR 当前逐页处理 PNG/JPEG/WebP，不直接导入 PDF；原图框仅到谱行，逐音符坐标/置信度没有伪造。
- IndexedDB 是本机浏览器存储，需要项目备份，未验证远程协作/云同步。
- 构建对 OpenCV 的 Node 专用 fs/path/crypto 分支有浏览器 externalized 警告；实际开发和生产 Worker 初始化均通过。可选 gl 链仍有 prebuild-install 弃用提示，安装脚本已禁用，不影响浏览器 SVG 路径。
- 未验证 Firefox、Safari、实体 MIDI 设备和超大型管弦乐工程。
